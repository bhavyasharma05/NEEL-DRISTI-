# Neel Drishti Frontend

This directory contains the modern React + Vite + TypeScript web application for **Neel Drishti**.

For complete project documentation, system architecture, backend setup, and API specifications, please refer to the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```

## Features
- **Landing Page**: Fluid wave animations, floating bubble particles, and platform statistics.
- **AI Chatbot**: Real-time SSE streaming, query suggestions, conversation history.
- **ARGO Map**: Spatial tracking of active, surfaced, and diving ARGO floats.
- **Ocean Insights**: Depth profiles for Temperature, Salinity, and Pressure across global basins.
- **Dashboard**: KPI statistics and trends.
- **Authentication**: Firebase authentication integration.
